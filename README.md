# LuckFox_YOLO

Пошаговая инструкция, как запустить детекцию объектов **YOLOv8** на NPU одноплатника **Luckfox Pico Mini** (Rockchip RV1103), обучить модель на **свой** объект и подключить к плате OLED-экран, который показывает количество найденных объектов и их координаты.

Это переработанная и расширенная инструкция по мотивам статьи [«Запускаем Yolo на пятирублёвой монете, или Luckfox Pico Mini»](https://habr.com/ru/articles/852376/) (Хабр, автор [ret7020](https://github.com/ret7020)) и репозитория [ret7020/Yolov8CustomNPU](https://github.com/ret7020/Yolov8CustomNPU). Здесь весь путь собран в одном месте: подготовка платы, съёмка и разметка своего датасета, обучение в Google Colab (пригодится, если у вас Windows или macOS), сборка и запуск на плате, и вывод результата на OLED-экран.

Инструкция полностью универсальна — вы можете обучить модель на **любой предмет**: кружку, отвёртку, деталь, игрушку — что угодно.

![Распиновка Luckfox Pico Mini](docs/images/pinout.png)

## Что в итоге получится

- Плата с камерой в реальном времени находит нужный вам объект (YOLOv8, инференс на NPU, ~10-15 FPS на 640×640, ~40-50 FPS на 320×320).
- Встроенный светодиод **USER** на плате загорается, когда объект найден.
- OLED-экран (128×64, I2C) показывает количество найденных объектов и координаты каждого.
- На компьютере можно смотреть картинку с камеры и лог детекций в реальном времени через ADB, без дополнительных проводов.

## Что нужно купить

| Что | Зачем | Примечание |
|---|---|---|
| Luckfox Pico Mini (A или B) | сама плата | версия B отличается наличием SPI NAND Flash на 128 МБ, для этой инструкции не критично |
| CSI-камера SC3336 | камера для платы | другие камеры платой не поддерживаются, ищите камеры, помеченные производителем «для Luckfox» |
| MicroSD-карта, 8 ГБ и больше | система + swap | лучше 16-32 ГБ, будет запас места |
| Кабель USB-C | питание и связь с ПК (ADB) | подойдёт обычный кабель для зарядки/данных |
| OLED-дисплей 128×64 на SSD1306/SSD1315, I2C | экран с результатами | опционально, см. [docs/07-oled-display.md](docs/07-oled-display.md) |
| Провода-перемычки / паяльник | подключение экрана | опционально |

## Структура репозитория

```text
LuckFox_YOLO/
├── docs/                    инструкции по шагам (см. выше) + картинки
├── colab/                   ноутбук/скрипты для Google Colab (обучение, экспорт в RKNN, сборка бинарника)
├── cpp/HelloDetector/       исходник программы детекции для платы (main.cc)
├── tools/
│   ├── dataset_capture/     маленькая программа для сбора датасета прямо с камеры платы
│   ├── labeler/             офлайн-разметчик рамок в браузере, без установки чего-либо
│   └── pc_monitor/          скрипт для ПК, показывает детекции и картинку с платы в реальном времени
└── model/                   labels.txt-заготовка
```
