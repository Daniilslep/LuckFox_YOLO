# 2. Прошивка Linux на плату и подключение по ADB

Плате нужна операционная система — используем готовый образ **Buildroot** от Luckfox (лёгкий Linux, в котором уже есть всё нужное для NPU и камеры). Ставим его на microSD-карту.

Ниже — способ для **Windows** (официальные инструменты Luckfox). Если у вас Linux или macOS — короткая альтернатива в конце файла.

## 2.1. Что скачать

Всё берём с официальной страницы загрузок: https://wiki.luckfox.com/Luckfox-Pico-RV1106/Downloads

- **Образ прошивки (firmware)** — Buildroot-образ для вашей версии платы:
  - `Luckfox_Pico_Mini_A_MicroSD_*` — для Mini A
  - `Luckfox_Pico_Mini_B_MicroSD_*` — для Mini B (если хотите ставить на SD, а не во встроенную Flash)
  - Страница с образами: https://wiki.luckfox.com/Luckfox-Pico-Plus-Mini/Flash-image
- **DriverAssistant** — драйвер USB для Windows, без него компьютер не увидит плату в режиме прошивки.
- **SD Card Formatter** — форматирование карты перед записью.
- **SocToolKit** — сама программа записи образа на карту.
- **ADB** — для связи с платой после прошивки (папку можно скачать там же, на странице загрузок).

## 2.2. Установка драйвера

1. Распакуйте DriverAssistant, запустите `DriverInstall.exe` **от имени администратора**.
2. Если видите кнопку «Uninstall Driver» — нажмите её первой (снимает старые/конфликтующие драйверы), затем «Install Driver».
3. Перезагрузите компьютер после установки.

## 2.3. Форматирование SD-карты

1. Установите SD Card Formatter, вставьте карту через кардридер.
2. Выберите нужный диск (внимательно проверьте букву диска!) и нажмите «Format».

## 2.4. Запись образа на карту

1. Распакуйте архив с образом прошивки в любую папку.
2. Запустите `SocToolKit.exe` **от имени администратора**, выберите модель процессора **RV1106** (используется и для RV1103).
3. Переключите инструмент в режим **SDTool**.
4. Вставьте SD-карту через USB-кардридер (не через слот в самой плате) — она должна появиться в списке USB-накопителей внутри SocToolKit.
5. Выберите **SD Card Boot**.
6. Через «импорт файлов» укажите папку с распакованным образом (файл `update.img` из образа сюда **не входит**, программа сама разберётся, какие файлы нужны).
7. Нажмите **Create SD Card** и дождитесь окончания записи.

Если карта не отображается в программе:
- запускайте SocToolKit строго от администратора;
- на время отключите антивирус;
- переподключите карту, не закрывая программу;
- используйте кардридер, а не сам слот платы.

## 2.5. Первое включение

1. Вставьте SD-карту в плату **контактами к плате** (в сторону платы).
2. Подключите Type-C кабель к компьютеру — это одновременно и питание, и связь.
3. На плате должен замигать индикатор **ACT** — значит, система загружается.

## 2.6. Подключение по ADB

ADB (Android Debug Bridge) — основной способ работать с платой: заходить в консоль, копировать файлы, запускать программы.

1. Распакуйте скачанный ADB куда-нибудь, например `C:\adb\`.
2. Добавьте эту папку в переменную среды `PATH` (Панель управления → Система → Дополнительные параметры системы → Переменные среды → `Path` → добавить путь к папке с `adb.exe`), либо всегда указывайте полный путь к `adb.exe`.
3. Откройте PowerShell или CMD и проверьте:

```powershell
adb devices
```

Плата должна появиться в списке со статусом `device`. Если ничего нет:

```powershell
adb kill-server
adb start-server
adb devices
```

4. Заходим в консоль платы:

```powershell
adb shell
```

Если вы увидели приглашение командной строки платы — прошивка и подключение прошли успешно, можно переходить к [03-first-boot-setup.md](03-first-boot-setup.md).

## 2.7. Если у вас Linux или macOS

Официальная документация приводит несколько альтернатив:

- **upgrade_tool** — консольная утилита от Rockchip, работает на Linux x86_64 и macOS, умеет прошивать SD-карту и встроенную Flash.
- Скрипт от сообщества **blkenvflash.py** (Python 3) — записывает образ на полностью неразмеченную SD-карту (сначала уберите с карты все разделы, например, через `GParted`), запускается так:

  ```bash
  sudo python3 blkenvflash.py /dev/sdX   # вместо /dev/sdX — ваша карта
  ```

- ADB на Linux ставится через пакетный менеджер: `sudo apt install adb` (Debian/Ubuntu) или `sudo pacman -S adb` (Arch).

Подробности и ссылки на скрипт — в оригинальной статье: https://habr.com/ru/articles/852376/ (раздел «Установка Linux»).
