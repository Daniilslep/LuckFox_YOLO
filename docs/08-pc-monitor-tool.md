# 8. Просмотр детекций с компьютера

Программа на плате и так пишет всё в консоль и сохраняет `out.jpg` на каждом кадре, но удобнее смотреть на это в реальном времени с компьютера, без постоянного `adb shell`. Для этого в репозитории есть [`tools/pc_monitor/detector_monitor.py`](../tools/pc_monitor/detector_monitor.py).

Он через ADB:

- проверяет, запущен ли `HelloDetector` на плате, и если нет — запускает сам;
- забирает лог с последними детекциями;
- забирает свежий `out.jpg`;
- показывает окно с картинкой, рамками и подписями объектов, плюс текстовую панель со списком координат.

## Установка зависимостей (на компьютере, не на плате)

```bash
pip install opencv-python numpy
```

Также нужен `adb` — тот же, что вы использовали при прошивке/заливке файлов (см. [02-flashing.md](02-flashing.md)). Скрипт ищет `adb` в `PATH`, в переменной окружения `ADB`, и в типичных путях Windows (в том числе `C:\Program Files\e2eSoft\iVCam\adb\adb.exe`). Если ваш `adb.exe` лежит в другом месте — пропишите полный путь в начале `detector_monitor.py` в функции `_find_adb()` или задайте `set ADB=C:\путь\adb.exe` перед запуском.

## Настройка под свой проект

В начале `detector_monitor.py` есть несколько переменных — поправьте, если у вас другие пути:

```python
REMOTE_DIR = "/root/detector"       # куда вы залили HelloDetector на плате
BINARY_NAME = "HelloDetector"
MODEL_PATH = "model/yolov8.rknn"
MIN_CONF = 0.50                     # порог уверенности для отображения
```

## Запуск

Windows:

```powershell
tools\pc_monitor\detector_monitor.cmd
```

Linux / macOS:

```bash
python3 tools/pc_monitor/detector_monitor.py
```

Откроется окно `detector live` с картинкой и подписями, а в консоли будет печататься список найденных объектов с координатами. Для выхода — клавиша **Q** в окне или `Ctrl+C` в консоли.

## Если детекции не появляются

- Убедитесь, что плата подключена и видна: `adb devices`.
- Если программа на плате уже была запущена вручную **без** перенаправления вывода в файл (как в примере из [06-build-and-deploy.md](06-build-and-deploy.md), напрямую `./HelloDetector ...`), у монитора не будет доступа к логу. Перезапустите программу на плате (`killall HelloDetector`) и просто запустите `detector_monitor.py` — он сам стартует программу с нужным логированием.
- Проверьте, что пути `REMOTE_DIR` / `BINARY_NAME` в скрипте совпадают с тем, куда вы реально залили файлы.
